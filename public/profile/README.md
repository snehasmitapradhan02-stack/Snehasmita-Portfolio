# Profile photo

Place the hero / about portrait here. Any one of these filenames works:

```
profile.webp
portrait.webp
snehasmita.webp
snehasmita-pradhan.webp
sneha profile.webp
photo.webp
me.webp
headshot.webp
```

Supported extensions: `.webp` `.jpg` `.jpeg` `.png` `.avif`

Suggested: square (1:1), at least 1000 × 1000 px, `.webp` under ~250 KB.

The image is masked into a circle, so a square crop with the head centred
in the upper-middle third works best. If no file is present, a designed
monogram placeholder is rendered instead.
